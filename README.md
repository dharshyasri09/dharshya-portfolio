# Dharshya Sri M — Portfolio

A responsive, light-minimal personal portfolio website built with HTML, CSS, and vanilla JavaScript.

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `dharshya-portfolio`).
2. Upload `index.html` and this README.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide your published website URL.
